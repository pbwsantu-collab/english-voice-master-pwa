# VOICE CHANGE MASTER

**Learn Active & Passive Voice — Understand. Practise. Master.**

Complete Progressive Web App for WBBSE / WBCHSE / Bengali-medium students based on *A Text-Book of Higher English Grammar* (Sections 191–206).

## Features

- **100% textbook content** — Sections 191–206, every example, Exercise 20 / 21 / 22(A) / 22(B)
- Bilingual (English + **বাংলা**) explanations and glossary
- Interactive Learn → Examples → Practice → Exercises flow
- Tense table + warning (Perfect Continuous has no Passive)
- Interrogative 3-step method, who → by whom
- Two objects, complex sentences, imperatives, infinitives, quasi-passive
- V1–V2–V3 dictionary with Bengali meanings
- Common mistakes list
- Local progress tracking
- Mobile-first UI, dark mode, searchable
- PWA-ready (manifest included)

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build
